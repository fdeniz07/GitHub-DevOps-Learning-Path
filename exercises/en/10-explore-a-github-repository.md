# Explore a GitHub Repository

## Objective

Inspect a GitHub repository in the browser and connect the UI to the underlying Git concepts you have already learned.

## Scenario

You are reviewing a repository on GitHub for the first time. You need to identify the main branch, inspect the file list, and understand how the visible project state connects to the commit history behind it.

## Tasks

1. Open a public repository on GitHub.
2. Identify the default branch and examine the repository home page.
3. Inspect the file tree and read the README file.
4. View the commit history and note how recent changes are grouped.
5. Explain how the repository view on GitHub connects to the local Git commands you already use.

## Expected Outcome

You can describe the GitHub repository interface and explain how it reflects Git history, branch structure, and project content.

## Self-Check

- [ ] I can identify a repository home page and its default branch.
- [ ] I understand that the GitHub UI is a shared view over Git data.
- [ ] I can explain why branches and commits are visible in the browser.
