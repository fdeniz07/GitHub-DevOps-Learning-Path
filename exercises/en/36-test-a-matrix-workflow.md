# Test a Matrix Workflow

## Objective

Design a matrix that tests supported runtime and operating-system combinations without hiding unsupported cases.

## Learning Outcomes

- calculate the combinations generated by a matrix;
- use `include` and `exclude` deliberately;
- select a useful `fail-fast` policy.

## Prerequisites

- Completed [GitHub Actions Matrix Builds](../../notebooks/en/36-github-actions-matrix-builds.md).
- A repository with a small test command.

## Scenario

Your project supports two runtimes on Ubuntu and Windows, but one old runtime is unsupported on Windows. Express that policy in one job.

## Tasks

### Task 1

Write a matrix with `os: [ubuntu-latest, windows-latest]` and two runtime values. List every initial combination.

### Expected Result

You can state the Cartesian product before applying exclusions.

### Task 2

Exclude the unsupported combination and set `fail-fast` according to whether cross-platform diagnosis is important.

### Expected Result

Only supported combinations run, and the failure policy is intentional.

### Task 3

Print both matrix values in the job and verify the run summary contains one clear result per combination.

### Expected Result

Every job is identifiable by its operating system and runtime.

## Challenge

Use `include` to mark one experimental combination as non-blocking, then explain the trade-off.

## Self-Assessment

- [ ] I can predict the expanded combinations.
- [ ] I can justify an exclusion.
- [ ] I can explain the effect of `fail-fast`.

## Common Mistakes

| Mistake                          | Solution                                 |
| -------------------------------- | ---------------------------------------- |
| Testing unsupported combinations | Encode support policy with `exclude`.    |
| Ambiguous logs                   | Print the matrix dimensions in each job. |
| Cancelling useful diagnostics    | Choose `fail-fast` based on the goal.    |

## Summary

You expressed a support policy as a readable, bounded matrix instead of duplicating jobs.
