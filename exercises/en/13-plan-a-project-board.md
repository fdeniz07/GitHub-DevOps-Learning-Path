# Plan a Project Board

## Objective

Design a simple GitHub Project board that reflects the work stages of a software team and apply it to realistic tasks.

## Scenario

Your team is shipping a small feature and needs a visible workflow for planning, implementation, and review. You want a project board that makes work visible without overly complex rules.

## Tasks

1. Define a board with at least four columns.
2. Add three example tasks to the board.
3. Assign one task to each stage of the workflow.
4. Describe what each column means in one sentence.
5. Explain why a visible workflow is useful for a team.

## Expected Outcome

You can explain how a GitHub Project board models work stages and helps a team coordinate effectively.

## Self-Check

- [ ] I can name at least three project board columns.
- [ ] I know how issues and pull requests fit into a board.
- [ ] I can explain why project visibility reduces confusion.
