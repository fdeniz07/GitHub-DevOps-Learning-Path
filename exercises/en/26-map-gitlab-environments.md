# Map GitLab Environments

## Objective

Define an understandable environment and promotion model for a small service.

## Tasks

1. Describe the purpose of `review`, `staging`, and `production` for a customer portal.
2. State which checks and approval are required before staging and production.
3. Record a rollback target and the first two signals to inspect after deployment.

## Expected Result

Your plan uses stronger controls for production than for a temporary review environment and promotes one tested version.

## Self-Assessment

- [ ] I can distinguish an environment from a job.
- [ ] I can state when manual approval is appropriate.
- [ ] I have a rollback and verification plan.
