# GitHub Deposunu Keşfetme

## Amaç

Katkı vermeden önce bir GitHub deposunu inceleyin.

## Görevler

1. README ve katkı kurallarını okuyun.
2. Lisans, issue, branch ve release bölümlerini inceleyin.
3. Depoyu klonlayın veya salt okunur açın.
4. Yapılandırılmış remote'u bulun.
5. Katkı akışını açıklayın.

## Beklenen Sonuç

Git ile GitHub'ı ayırt edebilir ve proje kurallarını bulabilirsiniz.
