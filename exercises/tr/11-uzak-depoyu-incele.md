# Uzak Depoyu İnceleme

## Görevler

1. Kendi fork'unuzu klonlayın.
2. `git remote -v` çıktısını inceleyin.
3. Orijinali `upstream` olarak ekleyin.
4. `git fetch upstream` çalıştırın.
5. Branchlerin nereye gönderildiğini açıklayın.

## Beklenen Sonuç

`origin` ve `upstream` ilişkisini doğru kurabilir, yerel kopyayı senkronize edebilirsiniz.
