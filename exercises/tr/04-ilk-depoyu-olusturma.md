# İlk Deponuzu Oluşturma

## Amaç

Doğru proje klasöründe yerel depo oluşturun ve `git status` çıktısını açıklayın.

## Senaryo

`team-handbook` adlı küçük bir proje başlatıyorsunuz. Klasörü oluşturun, Git'i başlatın ve henüz commitlenmemiş README dosyasını gözlemleyin.

## Görevler

1. `team-handbook` klasörünü oluşturup içine girin.
2. `git init` ve `git status` çalıştırın.
3. `README.md` oluşturun; ancak stage veya commit etmeyin.
4. Proje dosyası ile `.git` arasındaki farkı açıklayın.

## Beklenen Sonuç

Proje kökünü bilinçli seçebilir ve izlenmeyen dosyayı durum çıktısında tanıyabilirsiniz.

## Öz Kontrol

- [ ] `git init` öncesinde yolu kontrol ettim.
- [ ] Boş bir depoyu tanıyabiliyorum.
- [ ] README'nin neden izlenmeyen olduğunu açıklayabiliyorum.
