# Ein GitHub-Repository erkunden

## Ziel

Untersuche ein Repository, bevor du dazu beiträgst.

## Aufgaben

1. Lies README und CONTRIBUTING-Datei.
2. Prüfe Lizenz, Issues, Branches und Releases.
3. Klone das Repository oder öffne es schreibgeschützt.
4. Finde das konfigurierte Remote.
5. Beschreibe, wie ein Beitrag erfolgen soll.

## Erwartetes Ergebnis

Du kannst Git und GitHub unterscheiden und die Regeln eines Projekts finden.
