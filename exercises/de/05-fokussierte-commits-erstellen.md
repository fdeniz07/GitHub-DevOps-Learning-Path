# Fokussierte Commits erstellen

## Ziel

Erstelle kleine Commits und prüfe vor dem Speichern den Staging-Diff.

## Aufgaben

1. Ändere zwei fachlich getrennte Dateien.
2. Führe `git diff` aus.
3. Stage nur die erste Änderung.
4. Prüfe `git diff --staged`.
5. Committe sie mit einer aussagekräftigen Nachricht.
6. Wiederhole den Ablauf für die zweite Datei.

## Erwartetes Ergebnis

Jeder Commit beschreibt genau eine zusammenhängende Änderung.

## Selbstprüfung

- [ ] Ich prüfe den Diff vor dem Staging.
- [ ] Ich verwende klare Commit-Nachrichten.
- [ ] Ich kann staged und unstaged Änderungen unterscheiden.
