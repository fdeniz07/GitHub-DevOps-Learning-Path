# Das erste Repository erstellen

## Ziel

Erstelle ein lokales Repository im richtigen Projektordner und erkläre den Zustand mit `git status`.

## Szenario

Du beginnst das Projekt `team-handbook`. Erstelle den Ordner, initialisiere Git und beobachte anschließend eine unversionierte README-Datei.

## Aufgaben

1. Erstelle `team-handbook` und wechsle hinein.
2. Führe `git init` und `git status` aus.
3. Erstelle `README.md`, ohne sie zu stagen oder zu committen.
4. Erkläre den Unterschied zwischen Projektdatei und `.git`.

## Erwartetes Ergebnis

Du kannst die Projektwurzel bewusst wählen und eine unversionierte Datei im Status erkennen.

## Selbstprüfung

- [ ] Ich habe den Pfad vor `git init` geprüft.
- [ ] Ich kann ein leeres Repository erkennen.
- [ ] Ich weiß, warum die README zunächst unversioniert ist.
