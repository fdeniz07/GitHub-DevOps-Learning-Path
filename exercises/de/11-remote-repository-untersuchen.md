# Ein Remote-Repository untersuchen

## Aufgaben

1. Klone einen eigenen Fork.
2. Prüfe `git remote -v`.
3. Füge das Original als `upstream` hinzu.
4. Führe `git fetch upstream` aus.
5. Erkläre, wohin Branches gepusht werden.

## Ergebnis

Du kannst `origin` und `upstream` korrekt zuordnen und eine lokale Kopie synchronisieren.
