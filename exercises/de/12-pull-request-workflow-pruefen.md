# Pull-Request-Workflow prüfen

## Ziel

Bewerte einen PR als Reviewer.

## Aufgaben

1. Lies Titel und Beschreibung.
2. Prüfe den Diff und die Zielbranch.
3. Lies Statusprüfungen.
4. Hinterlasse einen konkreten Kommentar.
5. Entscheide, ob der PR bereit zum Mergen ist.

## Ergebnis

Du kannst technische und kommunikative Qualität gemeinsam bewerten.
