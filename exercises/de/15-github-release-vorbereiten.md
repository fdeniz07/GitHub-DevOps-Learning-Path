## Aufgaben

1. Wähle eine Version nach Semantic Versioning.
2. Liste Features und Fehlerkorrekturen.
3. Schreibe Release Notes.
4. Entscheide zwischen Draft, Prerelease und stable.
5. Erstelle eine Release-Readiness-Checkliste.

## Ergebnis

Du kannst Tag, Notes und Assets als zusammenhängende Veröffentlichung planen.
