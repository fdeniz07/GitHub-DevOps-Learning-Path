# Quiz: Mit Commits arbeiten

## Fragen

1. Welche Aufgabe hat `git add`?
2. Was speichert `git commit`?
3. Wozu dient `git diff --staged`?
4. Warum sind fokussierte Commits nützlich?

## Antworten

1. Es nimmt ausgewählte Änderungen in den Staging-Bereich auf.
2. Einen Historienpunkt mit den staged Änderungen.
3. Es zeigt, was im nächsten Commit enthalten wäre.
4. Sie machen Prüfung, Rücknahme und Erklärung leichter.

## Praxisszenario

Zwei unabhängige Änderungen befinden sich in einem Staging-Diff. Wie gehst du vor?

**Antwort:** Eine Änderung aus dem Staging entfernen oder gezielt einzeln stagen und zwei fokussierte Commits erstellen.
