## GitLab Merge Requests und Code Review Quiz

### Frage 1 - Multiple Choice

Was macht einen MR gut prüfbar?

- A. Mehrere unzusammenhängende Verbesserungen
- B. Eine zusammenhängende Änderung mit Zweck und Prüfangaben
- C. Keine Beschreibung und viele Commits
- D. Eine gemergte fehlgeschlagene Pipeline

**Antwort:** B. Ein fokussierter MR verringert Risiko und liefert Kontext.

### Frage 2 - Richtig oder Falsch

Eine erfolgreiche Pipeline ersetzt immer eine erforderliche menschliche Freigabe.

**Antwort:** Falsch. Pipeline und Freigabe sind getrennte Projektkontrollen.

### Frage 3 - Kurzantwort

Welche drei Nachweise prüfst du vor dem Merge?

**Erwartete Antwort:** Erforderliche Freigaben, gelöste erforderliche Diskussionen und Status der Pflicht-Pipeline.

### Frage 4 - Praxisfall

Du entdeckst einen Tippfehler, der nichts mit einem MR für einen defekten Befehl zu tun hat. Was schreibst du?

**Erwartete Antwort:** Einen klaren nicht blockierenden Vorschlag oder ein Folge-Work-Item. Der kleine Pflicht-Fix soll keinen fremden Umfang erhalten.
