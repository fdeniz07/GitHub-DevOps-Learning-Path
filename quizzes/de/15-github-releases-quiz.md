1. Worauf zeigt ein Tag?
2. Was erklären Release Notes?
3. Was unterscheidet Prerelease und stable?

**Antworten:** Ein Tag zeigt auf einen Commit. Notes erklären Änderungen und Upgrade-Hinweise. Ein Prerelease dient dem Testen; stable ist für normalen Gebrauch bestimmt.
