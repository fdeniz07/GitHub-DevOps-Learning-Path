# Git installieren - Quiz

## Multiple Choice

### Frage 1

Welcher Befehl prüft Git im aktuellen Terminal?

- A. `git init`
- B. `git --version`
- C. `git commit`

#### Antwort: Frage 1

**B.** Der Befehl führt Git aus und gibt die installierte Version aus.

### Frage 2

Warum ist nach einer Windows-Installation ein neues Terminal nötig?

- A. Neues Terminal lädt den aktualisierten PATH-Wert.
- B. Es erstellt automatisch ein Repository.
- C. Es sendet Git an GitHub.

#### Antwort: Frage 2

**A.** Bereits geöffnete Terminals kennen den neuen Git-Ort möglicherweise nicht.

## Kurzantwort

### Frage 3

Welche zwei Werte nutzt Git als grundlegende Commit-Identität?

#### Erwartete Antwort: Frage 3

Name und E-Mail-Adresse.

### Frage 4

`user.email` ist leer. Was ist der kleinste sichere nächste Schritt?

#### Erwartete Antwort: Frage 4

Eine passende E-Mail mit `git config --global user.email "du@example.com"` setzen und anschließend wieder auslesen.
