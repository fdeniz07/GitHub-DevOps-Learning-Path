1. Was ist der Unterschied zwischen Git und GitHub?
2. Was bedeutet `origin`?
3. Was macht `git fetch`?
4. Warum sollte man Repository-Regeln lesen?

**Antworten:** Git ist lokale Versionsverwaltung; GitHub hostet und unterstützt Zusammenarbeit. `origin` ist ein Remote-Name. `fetch` lädt Remote-Informationen ohne Integration. Regeln verhindern falsche Beiträge.
