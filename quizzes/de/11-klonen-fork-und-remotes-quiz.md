1. Was ist ein Clone?
2. Was ist ein Fork?
3. Wofür steht `upstream`?
4. Wohin wird ein Feature-Branch im Fork-Workflow gepusht?

**Antworten:** Clone ist eine lokale Kopie; Fork ist eine eigene GitHub-Kopie. `upstream` zeigt auf das Original. Der Feature-Branch geht zu `origin`.
