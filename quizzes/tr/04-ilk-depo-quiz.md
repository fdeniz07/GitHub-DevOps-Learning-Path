# İlk Depo Quiz'i

## Sorular

1. Yerel depo oluşturmak için hangi komut kullanılır?
2. `git status` neyi gösterir?
3. Git yönetim bilgilerini nerede saklar?
4. Neden genel üst klasörde `git init` çalıştırılmamalıdır?

## Cevaplar

1. `git init`.
2. Branch, çalışma dizini ve staging alanının durumunu.
3. Gizli `.git` klasöründe.
4. Birden fazla projenin aynı geçmişe girmesini önlemek için.

## Senaryo

`README.md` status çıktısında izlenmeyen görünüyor. Bu ne demektir?

**Cevap:** Git dosyayı görüyor; ancak dosya henüz stage edilip commitlenmemiştir.
