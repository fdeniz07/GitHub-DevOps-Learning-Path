# Dallanma Stratejileri Quiz'i

## Sorular

1. Branch nedir?
2. Yeni branch oluşturup ona geçmek için hangi komut kullanılır?
3. Feature branch neden kullanılır?
4. Branch ne zaman silinebilir?

## Cevaplar

1. Bir commit'i gösteren adlandırılmış hareketli işaretçidir.
2. `git switch -c ISIM`.
3. İlişkili işi `main`den izole eder.
4. Değişiklikler merge edildikten veya bilinçli bırakıldıktan sonra.

## Senaryo

Hangi branchte olduğunuzu bilmiyorsunuz. Hangi komut yardımcı olur?

**Cevap:** `git branch --show-current`.
