# Commitlerle Çalışma Quiz'i

## Sorular

1. `git add` ne yapar?
2. `git commit` neyi kaydeder?
3. `git diff --staged` neden kullanılır?
4. Odaklı commitler neden faydalıdır?

## Cevaplar

1. Seçilen değişiklikleri staging alanına alır.
2. Hazırlanan değişiklikleri geçmiş noktası olarak kaydeder.
3. Bir sonraki committe yer alacak içeriği gösterir.
4. İnceleme, geri alma ve açıklamayı kolaylaştırır.

## Senaryo

Staging diff içinde iki bağımsız değişiklik var. Ne yaparsınız?

**Cevap:** Birini stagingden çıkarır veya değişiklikleri tek tek stage ederek iki odaklı commit oluşturursunuz.
