# GitHub Actions Runner'ları Quiz'i

### Soru 1

GitHub tarafından barındırılan bir runner'ın önemli bir avantajı nedir?

**Cevap:** Genellikle GitHub tarafından yönetilen temiz ve geçici bir makinedir; yerel bakımı azaltır.

### Soru 2

Doğru mu, yanlış mı: Bir runner etiketi runner'ı kullanma izni verir.

**Cevap:** Yanlış. Etiketler job'ları yönlendirir; gruplar ve politikalar erişimi kontrol eder.

### Soru 3

Kendi runner'ını barındırmak neden bir güvenlik sorumluluğudur?

**Cevap:** Sahibi, workflow kodunu çalıştıran bir makineyi yamalamalı, yalıtmalı, izlemeli, temizlemeli ve kontrol etmelidir.

### Soru 4

Hassas self-hosted runner'lar mevcutken fork pull request'leri nasıl ele alınmalıdır?

**Cevap:** Güvenilmeyen kodu hosted veya yalıtılmış runner'larda tutun ve hassas erişimden önce inceleme ya da onay isteyin.
