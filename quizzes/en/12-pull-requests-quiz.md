# Pull Requests Quiz

## Multiple Choice

### Question 1

What is the main purpose of a pull request?

- A. To delete a branch
- B. To request review and approval before merging changes
- C. To create a new repository
- D. To replace Git on a local machine

#### Answer and Explanation: Question 1

**B.** A pull request is a structured proposal for review and approval before the change is merged.

### Question 2

What does the base branch represent in a pull request?

- A. The branch being reviewed
- B. The branch where the current code lives before the change is merged
- C. The local working directory
- D. The remote clone URL

#### Answer and Explanation: Question 2

**B.** The base branch is the target destination branch for the PR.

## Short Answer

### Question 3

Why is a pull request useful in a team project?

#### Answer and Explanation: Question 3

It creates a visible review process, clarifies intent, supports discussion, and helps prevent unreviewed changes from being merged.

## Practical Scenario

A feature branch has been pushed and opened as a PR. A reviewer asks for a change before approval. What should happen next?

### Expected Answer: Practical Scenario

The author updates the branch with the requested changes, pushes the updates, and the PR is reviewed again until the team is satisfied.
