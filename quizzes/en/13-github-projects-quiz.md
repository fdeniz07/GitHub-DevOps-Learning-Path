# GitHub Projects Quiz

## Multiple Choice

### Question 1

What is the main purpose of a GitHub Project?

- A. To replace the Git repository itself
- B. To provide a visual workflow for tracking work items and delivery progress
- C. To manage local Git branches
- D. To deploy software automatically

#### Answer and Explanation: Question 1

**B.** A GitHub Project is a visual planning board that helps teams track tasks and progress.

### Question 2

Which of the following is most commonly tracked on a project board?

- A. A remote URL
- B. A Git branch name only
- C. Issues and pull requests
- D. Local repository settings

#### Answer and Explanation: Question 2

**C.** Issues and pull requests are common work items used on a GitHub Project board.

## Short Answer

### Question 3

Why are columns such as _In Progress_ and _Done_ useful on a project board?

#### Answer and Explanation: Question 3

They make the workflow visible and help the team understand current work status without asking each person individually.

## Practical Scenario

A team creates a board with Backlog, In Progress, Review, and Done columns. One task has been implemented and is now waiting for feedback. Which column is most appropriate?

### Expected Answer: Practical Scenario

The task should be placed in the **Review** column because it is ready for evaluation before being marked as complete.
