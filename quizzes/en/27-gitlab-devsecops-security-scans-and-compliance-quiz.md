# DevSecOps, Security Scans & Compliance Quiz

### Question 1

What is the role of a scan finding?

**Answer:** It is evidence that requires contextual triage, ownership, and a documented decision.

### Question 2

What must happen first when a secret is exposed?

**Answer:** Revoke or rotate it; removing a line alone does not contain exposure.

### True or False

A passed security job alone proves full compliance.

**Answer:** False. Compliance requires the complete required control set and evidence.
