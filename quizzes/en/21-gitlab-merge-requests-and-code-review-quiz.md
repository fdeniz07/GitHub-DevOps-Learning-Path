## GitLab Merge Requests and Code Review Quiz

### Question 1 - Multiple Choice

What makes an MR easiest to review?

- A. Several unrelated improvements
- B. One coherent change with purpose and verification details
- C. No description and many commits
- D. A merged failed pipeline

**Answer:** B. A focused MR reduces review risk and provides usable context.

### Question 2 - True or False

A successful pipeline always replaces required human approval.

**Answer:** False. Pipeline and approval requirements are separate project controls.

### Question 3 - Short Answer

What three kinds of evidence should you check before merging?

**Expected Answer:** The required approvals, required discussion resolution, and required pipeline status.

### Question 4 - Practical Scenario

You notice a typo unrelated to an MR that fixes a broken command. What should you write?

**Expected Answer:** Leave a clear non-blocking suggestion or create follow-up work; do not turn a small required fix into unrelated scope.
