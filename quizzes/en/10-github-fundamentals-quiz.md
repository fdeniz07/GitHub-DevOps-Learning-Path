# GitHub Fundamentals Quiz

## Multiple Choice

### Question 1

Which statement best describes the relationship between Git and GitHub?

- A. GitHub is a replacement for Git.
- B. Git records local history; GitHub hosts and shares that history for collaboration.
- C. GitHub only stores binary files.
- D. Git only works online.

#### Answer and Explanation: Question 1

**B.** Git manages project history locally; GitHub provides a shared platform around Git repositories for collaboration and visibility.

### Question 2

What does `git clone` do?

- A. Deletes a remote repository
- B. Creates a local copy of a repository with its history and branch metadata
- C. Creates a branch on GitHub
- D. Merges all branches automatically

#### Answer and Explanation: Question 2

**B.** A clone creates a working copy locally from a remote repository.

## True or False

### Question 3

A pull request is only useful when the repository is already fully merged.

#### Answer and Explanation: Question 3

**False.** A pull request is used before merge to review and discuss proposed changes.

## Practical Scenario

You created a feature branch locally, committed changes, and want other contributors to see them. Which command should you run next?

### Expected Answer: Practical Scenario

`git push origin <branch-name>`.
