# GitHub Marketplace Actions Quiz

### Question 1

Why is a full commit SHA useful for an action reference?

**Answer:** It selects an exact revision and makes changes reviewable and reproducible.

### Question 2

Where should you learn an action's input names and output names?

**Answer:** In its `action.yml` metadata and maintained documentation.

### Question 3

True or False: Popularity alone is sufficient supply-chain evidence.

**Answer:** False. Source, provenance, dependencies, permissions, maintenance, and behavior still need review.

### Question 4

What is the least-privilege principle for a Marketplace action?

**Answer:** Give the action only the inputs, secrets, and token permissions required for its task.
