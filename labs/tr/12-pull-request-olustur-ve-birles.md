## Görevler

1. Feature branch oluşturun.
2. Odaklı değişikliği commit edip push edin.
3. GitHub'da PR açın.
4. Diff, kontroller ve review yorumlarını inceleyin.
5. İstenen düzeltmeleri aynı branchte yapın.
6. Onaydan sonra merge edin.

## Beklenen Sonuç

Branch, review ve merge akışını baştan sona açıklayabilirsiniz.
