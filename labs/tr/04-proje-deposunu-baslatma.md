# Proje Deposunu Başlatma

## Amaç

`release-notes` projesi için depo oluşturun ve sınırını kontrol edin.

## Gereksinimler

- Git kurulmuş ve yapılandırılmış olmalı.
- Deneme klasörü oluşturma izniniz olmalı.
- Metin düzenleyici kullanabilmelisiniz.

## Görevler

1. `release-notes` klasörünü oluşturup içine girin.
2. `git init` ve `git status` çalıştırın.
3. İzlenmeyen bir `README.md` oluşturun.
4. `.git` klasörünün rolünü ve üst klasörde depo başlatmanın riskini açıklayın.

## Kontrol Listesi

- [ ] Status doğru klasörde çalışıyor.
- [ ] Henüz commit oluşturulmadı.
- [ ] README izlenmeyen olarak görünüyor.
- [ ] Üst klasör yanlışlıkla depo yapılmadı.
