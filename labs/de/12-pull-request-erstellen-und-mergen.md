## Aufgaben

1. Erstelle einen Feature-Branch.
2. Committe und pushe eine fokussierte Änderung.
3. Öffne auf GitHub einen Pull Request.
4. Prüfe Diff, Checks und Review-Kommentare.
5. Aktualisiere den Branch bei Änderungswünschen.
6. Merge erst nach Freigabe.

## Ergebnis

Du kannst den kompletten Branch-Review-Merge-Ablauf erklären.
