# Ein Projekt-Repository initialisieren

## Ziel

Initialisiere ein Repository für `release-notes` und prüfe seine Grenze.

## Voraussetzungen

- Git ist installiert und konfiguriert.
- Du kannst einen Übungsordner erstellen.
- Du hast einen Texteditor.

## Aufgaben

1. Erstelle `release-notes` und wechsle hinein.
2. Führe `git init` und `git status` aus.
3. Erstelle eine unversionierte `README.md`.
4. Erkläre, warum `.git` zum Projekt gehört und warum der Elternordner ungeeignet wäre.

## Prüfliste

- [ ] Der Status läuft im richtigen Ordner.
- [ ] Es wurde noch kein Commit erstellt.
- [ ] Die README erscheint als unversioniert.
- [ ] Der Elternordner enthält keine versehentlich initialisierten Repository-Daten.
